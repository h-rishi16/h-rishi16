## Flagship Systems

### 1. [OURE — Orbital Uncertainty & Risk Engine](https://github.com/h-rishi16/OURE)
> *Enterprise-grade Space Situational Awareness (SSA) platform for satellite collision prediction and maneuver optimization.*
- **Core Math:** SGP4 / High-Precision Orbit Propagation (HPOP), Foster's $P_c$ algorithm on encounter B-plane, and SLSQP avoidance optimization.
- **Performance:** Optimized with Cython C-extensions, fully instrumented with Prometheus & Grafana, 83%+ automated test coverage in CI/CD.
- **Deliverables:** Published on **[PyPI (`pip install oure`)](https://pypi.org/project/oure/)** and deployed with an interactive **[3D WebGL Visualization](https://oure-pi.vercel.app)**.

### 2. [Sentinel Risk Intelligence Platform](https://github.com/h-rishi16/sentinel)
> *Unified quantitative risk management and financial surveillance terminal.*
- **Engines:** Real-time transaction fraud detection (XGBoost), credit default modeling (PD/EL), portfolio Value at Risk (Monte Carlo 99% VaR with Kupiec POF testing), and GARCH(1,1) volatility forecasting.
- **Architecture:** High-throughput FastAPI backend integrated natively with an interactive HTMX + Tailwind CSS dark-mode terminal.
- **Live Deployment:** **[Sentinel Cloud Terminal](https://sentinel-risk-platform.onrender.com/)**.
